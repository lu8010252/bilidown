Bilidown Windows 本机版
========================

使用：
1. 把 ffmpeg.exe 放到本目录（或本目录下的 bin 文件夹）。
   如果你以前装过原版 Bilidown，把它安装目录里 bin\ffmpeg.exe 复制过来即可。
2. 双击 bilidown.exe，会弹出一个黑色窗口（里面是运行日志，关掉窗口 = 退出程序），
   并自动用默认浏览器打开 http://127.0.0.1:8098 。
3. 首次使用在页面里扫码登录 B 站。

说明：
- 只监听 127.0.0.1，局域网内其他设备访问不到。
- 视频直接保存在本目录的 download 文件夹（可在“设置中心”修改），
  任务列表里点“打开位置”会在资源管理器里选中文件。
- 数据（登录状态、任务记录）保存在本目录的 data.db。
- 端口被占用时：在命令行里先执行 set BILIDOWN_PORT=8099 再运行。
